Catálogo, horario e inventario (dueño)

Las marcas, productos y vehículos se crean por semilla (data-demo.sql) o vía solicitud aprobada por el admin — no hay alta directa por HTTP. Aquí se opera lo que sí es directo.

Actualizar precio — PUT /api/v1/negocios/me/productos/{id}/precio

Horario abierto (L–D 00:00–23:59) — PUT /api/v1/negocios/me/horarios

Registrar lote — POST /api/v1/inventario/lotes

La caducidad debe ser > hoy+7 días (RN-030).

Jornada y vehículo

Iniciar jornada — POST /api/v1/repartidores/me/jornada

Cargar más stock — POST /api/v1/inventario/carga-vehiculo
